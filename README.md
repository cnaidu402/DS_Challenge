# Data Science Intern Build Challenge

A lightweight build challenge for Data Science Intern candidates to show how they think, build, and work with AI.

This is not meant to be a sprawling take-home assignment. The goal is to build one small useful artifact from a messy fictional dataset and briefly explain your choices.

## Quick Version

You have 90 minutes.

Build the smallest useful thing you can for a teammate using the dataset in [sample-data/product_usage_events.csv](sample-data/product_usage_events.csv).

Acceptable artifacts include:

- a short notebook;
- a small Streamlit app;
- a simple script with clear output;
- a lightweight web page;
- a tiny internal-tool style interface.

Please also include:

- `README.md`: what you built, who it is for, assumptions, data issues, and what you would do next;
- `AI_NOTE.md`: whether/how you used AI, what helped, and what you verified yourself.

## What We Care About

- Scope judgment: did you pick something finishable and useful?
- Messy-data comfort: did you notice weirdness without getting stuck?
- Product sense: would this help a real teammate?
- Engineering fundamentals: does it run, and is it understandable?
- Communication: can you explain assumptions and tradeoffs clearly?
- AI collaboration: if you used AI, did you use it thoughtfully?

## What We Do Not Care About

- Perfect polish.
- A complex model.
- A long report.
- Legal-tech knowledge.
- LeetCode-style cleverness.

Read the full prompt in [challenge.md](challenge.md).
